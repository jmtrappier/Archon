### 1. Global Scrollbar Styling (`src/index.css`)

#### New CSS Implementation
```css
/* Global scrollbar styling for entire application */
html {
  scrollbar-width: thin;
  scrollbar-color: hsl(var(--muted-foreground) / 0.3) transparent;
}

html::-webkit-scrollbar {
  width: 8px;
  height: 8px;
}

html::-webkit-scrollbar-track {
  background: hsl(var(--background));
}

html::-webkit-scrollbar-thumb {
  background-color: hsl(var(--muted-foreground) / 0.3);
  border-radius: 4px;
  border: 1px solid hsl(var(--background));
  transition: all 0.2s ease;
}

html::-webkit-scrollbar-thumb:hover {
  background-color: hsl(var(--muted-foreground) / 0.5);
}

/* Apply to all scrollable elements by default */
* {
  scrollbar-width: thin;
  scrollbar-color: hsl(var(--muted-foreground) / 0.3) transparent;
}
```

#### Specialized Classes Added
1. **`.tree-scrollbar`**: Auto-hide scrollbar for TreeView
   - Transparent by default
   - Visible on hover/focus
   - 6px width for discretion

2. **`.custom-scrollbar`**: Standard discrete scrollbar
   - 6px width
   - Hover scale effect (scaleX 1.2)

3. **`.scrollbar-thin`**: Details panel scrollbar
   - Optimized for side panels
   - Subtle hover effects
