# Story 4.11: Revoir Présentation des Projets

## Status
Draft

## Story

**As a** Product Owner managing multiple projects in Archon-TRAXIS,
**I want** an enhanced project presentation interface that clearly shows project hierarchy, progress, and health metrics,
**so that** I can efficiently assess project status, navigate to specific EPICs/Stories/Tasks, and make informed decisions about project priorities and resource allocation.

## Acceptance Criteria

1. **Project Overview Dashboard**: Display all projects with key metrics (progress, EPICs count, Stories count, Tasks count, completion rate)
2. **Hierarchical Navigation**: Clear entry points to navigate into EPICs → Stories → Tasks hierarchy from project level
3. **Visual Health Indicators**: Color-coded status indicators for project health (progress, blocker detection, MVP status)
4. **Multiple View Modes**: Support different visualization formats (cards, table, kanban, timeline) for different use cases
5. **Search and Filtering**: Advanced filtering by status, priority, MVP flag, assignee, progress range
6. **Real-time Updates**: Live updates via Socket.IO when projects/EPICs/Stories/Tasks change
7. **Quick Actions**: One-click access to common actions (create EPIC, view details, archive project)
8. **Progress Visualization**: Clear progress indicators showing completion across hierarchy levels
9. **Performance Optimization**: Fast loading with pagination, lazy loading, and efficient data fetching
10. **Mobile Responsive**: Fully functional on mobile devices with touch-friendly interactions

### API Specifications
[Source: docs/docs/architecture.mdx#access-patterns]

**Required API Endpoints:**
- `GET /api/projects` - Enhanced with hierarchy metrics
- `GET /api/projects/{id}/summary` - Project dashboard data
- `GET /api/projects/{id}/health` - Health indicators
- `PUT /api/projects/{id}` - Project updates
- `DELETE /api/projects/{id}` - Project archival

**Socket.IO Events:**
- Room: `projects_list` for project list updates
- Events: `project_updated`, `project_created`, `project_archived`
- Pattern: Join room on component mount, leave on unmount
