# Story 4.5: Visualisation des Dépendances

## Status
Draft

## Story

**As a** project manager using Archon-TRAXIS,
**I want** visual representation of dependencies between Epics, Stories, and Tasks,
**so that** I can understand project relationships and identify potential blocking issues.

## Acceptance Criteria

1. **Dependency Graph Component**: Create interactive dependency visualization component
2. **Multi-Level Dependencies**: Show dependencies between Epics, Stories, and Tasks
3. **Dependency Types**: Support different dependency types (blocks, depends_on, related_to)
4. **Interactive Graph**: Clickable nodes for navigation and dependency management
5. **Dependency Creation**: UI for creating dependencies between hierarchy elements
6. **Dependency Management**: Edit and delete existing dependencies
7. **Visual Indicators**: Clear visual indicators for different dependency types and statuses
8. **Performance Optimization**: Efficient rendering for large dependency graphs

### Data Models
**Dependency Interface**:
```typescript
interface Dependency {
  id: string;
  from_type: 'epic' | 'story' | 'task';
  from_id: string;
  to_type: 'epic' | 'story' | 'task';
  to_id: string;
  dependency_type: 'blocks' | 'depends_on' | 'related_to';
  created_at: string;
  updated_at: string;
}

interface DependencyNode {
  id: string;
  type: 'epic' | 'story' | 'task';
  title: string;
  status: string;
  progress?: number;
  position?: { x: number; y: number };
}

interface DependencyEdge {
  id: string;
  source: string;
  target: string;
  type: 'blocks' | 'depends_on' | 'related_to';
  status?: 'active' | 'resolved' | 'blocked';
}
```
[Source: Epic 1 BDD implementation + Epic 2 Backend Services]

### API Specifications
**Dependency Endpoints**:
- `GET /api/projects/{project_id}/dependencies` - Get all dependencies for project
- `POST /api/dependencies` - Create new dependency
- `GET /api/dependencies/{id}` - Get dependency details
- `PUT /api/dependencies/{id}` - Update dependency
- `DELETE /api/dependencies/{id}` - Delete dependency
- `GET /api/{type}/{id}/dependencies` - Get dependencies for specific element
