# Story 4.2: Story View et Composants Story

## Status
Draft

## Story

**As a** project manager using Archon-TRAXIS,
**I want** a dedicated view for Stories with their associated components,
**so that** I can manage Story-level information and navigate down to Tasks within that Story.

## Acceptance Criteria

1. **Story View Component**: Create a dedicated `StoryView` component that displays Story details
2. **Story Card Component**: Create reusable `StoryCard` component for Story list displays
3. **Story Navigation**: Navigation from Epic view to Story view and from Story view to Tasks
4. **Story CRUD Operations**: Full Create, Read, Update, Delete operations for Stories
5. **Story Status Management**: Support Story statuses (todo, doing, review, waiting, done)
6. **Story Progress Display**: Show calculated progress based on child Tasks
7. **Story Priority Management**: Support Story priority levels and visual indicators
8. **MVP Flag Support**: Support for MVP flagging of critical Stories
9. **Epic Context Display**: Show parent Epic information within Story view

### Data Models
**Story Interface** (based on backend schema):
```typescript
interface Story {
  id: string;
  epic_id: string;
  title: string;
  description: string | null;
  status: 'todo' | 'doing' | 'review' | 'waiting' | 'done';
  priority: 'low' | 'medium' | 'high' | 'critical';
  mvp_flag: boolean;
  progress?: number; // calculated from child Tasks
  created_at: string;
  updated_at: string;
}

interface StoryWithEpic extends Story {
  epic: {
    id: string;
    title: string;
    project_id: string;
  };
}
```
[Source: BMAD Epic 1 implementation report + Epic 3 MCP extension]

### API Specifications
**Story Endpoints** (from backend implementation):
- `GET /api/epics/{epic_id}/stories` - List Stories for Epic
- `POST /api/stories` - Create new Story
- `GET /api/stories/{story_id}` - Get Story details with Epic context
- `PUT /api/stories/{story_id}` - Update Story
- `DELETE /api/stories/{story_id}` - Delete Story
- `GET /api/stories/{story_id}/tasks` - Get Tasks for Story

All endpoints support ETag caching and follow existing API patterns.
[Source: Epic 2 Backend Services implementation]
